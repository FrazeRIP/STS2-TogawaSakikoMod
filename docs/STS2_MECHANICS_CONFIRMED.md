# 二代机制核对（2026-10-25）

本文件记录本会话明确确认的二代规则，优先于旧的一代移植记录。卡牌表尚未逐张确认，不代表全部卡牌已按表改版。

## 移除

- 普通移除选择永久牌组中的可移除卡，不从战斗牌堆选临时牌。
- 删除永久本体，同时删除通过 DeckVersion 指向它的手牌、抽牌堆、弃牌堆、消耗堆、出牌区实例。
- 不按卡名删除其他独立的同名牌。临时生成且没有永久本体的牌不可移除。
- 无法移除的卡不进入候选。没有合法目标时不弹出空选择界面。
- 乌托邦的旧版“被移除时改为打出”特例取消。
- 月光奏鸣曲的移除改为当场选择；堕天的三选一范围、无畏和如愿以偿的候选改为永久牌组。
- 愚神升级版原有七张移除改为从永久牌组随机抽取可移除目标；未升级的消耗仍沿用原效果。费用、伤害、移除数量等后续逐卡核对。
- 变化、消耗及特殊测试牌的“战后删牌奖励”不当作普通移除指令批量重写。

## 加入牌组与加入手牌

- 在进行中的战斗里，“加入牌组”同时加入永久本体及一张关联的手牌实例。
- 直接新增、复制新增及幻影／元素衍生牌使用同一入口。升级状态保留，不重复产生战斗实例。
- 明确只写“加入手牌”的生成仍是临时牌。例如 Crychic 的幻影不进入永久牌组。
- 战斗外及结算阶段没有可用的战斗手牌，只加入永久牌组。
- 手牌容量沿用游戏原生加牌命令，不另行修改上限。

## 气焰（ArdorPower）

- 每层使持有者造成和受到的每段攻击伤害各增加 1。
- 双方都持有时，各自贡献自己的加值。非攻击伤害不受影响。
- 属于可叠层正面状态，整场战斗保留，攻击和回合结束不消耗。
- 使用原生伤害加算阶段，与其他伤害加算／倍率共同结算。
- 状态 ID：TOGAWASAKIKO-ARDOR_POWER。中英文名称和说明已添加，暂用力量图标。
- 尚未把未核对的卡牌接入气焰获取，也未改变它们的数值。
