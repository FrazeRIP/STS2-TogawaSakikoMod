## Native conversion rules

- `!D!`, `!B!`, and `!M!` become STS2 dynamic variables `Damage`, `Block`, and `MagicNumber` with upgrade-difference formatting.
- The Raise the Bet custom Strength variable becomes `Strength`. STS1 energy icons become the native energy-icon formatter.
- STS1 `NL`, color prefixes, custom keyword prefixes, and card-name stars become native newlines and BBCode.
- Source upgrade descriptions use the native `IfUpgraded` formatter only around changed text fragments. Existing Phase N2/N3 live entries retain their already-validated semantic variable names.
- No model is enabled by this catalog generation; normal pools remain behavior-gated.
