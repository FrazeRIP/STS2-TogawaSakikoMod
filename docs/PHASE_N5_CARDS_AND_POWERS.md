# Phase N5: Cards and Powers

Status: active. Batch N5.1 is accepted; Phase N5 is not complete.

Baseline: Slay the Spire 2 `v0.111.0` / `41cef1ea`.

## Current parity

- Cards: 11 of 95 native; 84 still require native behavior. Nine of the 95 are disabled in the STS1 source and must remain outside normal generation.
- Powers: 2 of 36 native; 34 still require native behavior or an explicit base-game reuse decision.
- Audio: all 58 STS1 files are packaged; three direct card voice routes are wired and verified.
- Art: all card slots have exact 250x190 and 500x380 files. `Weakness` uses the generated replacement-ready placeholder because the STS1 project has no portrait for it.

The machine-readable source of truth is `FULL_PORT_PARITY_INVENTORY.json`; `FULL_PORT_PARITY_INVENTORY.md` is its generated review view.

`A Split Moment` now uses the same Sakiko voice path. The shared voice command preserves the STS1 five-second per-player cooldown, routes through the SFX bus, skips non-interactive diagnostics, and frees its player node after playback. It does not introduce an external audio dependency.

The STS2 rich-text energy formatter requires a 24x24 pool-named glyph at `res://images/packed/sprite_fonts/togawa_sakiko_energy_icon.png`. The build derives this compatibility path from the existing Sakiko `text_energy.png`, exports it explicitly, and validates its loadability and dimensions. It is a path/layout compatibility copy, not replacement art.

## Dependency order for remaining work

1. Port foundational special cards, curses, and paired powers that are generated by multiple normal cards: Protection, Radiance, Voice, Kindness, Black Keys, White Keys, Amoris, Doloris, Mortis, Oblivionis, and Timoris.
2. Port common cards whose only remaining dependencies are those foundations and the Phase N3 deck commands: Budget Bento, Dark Heaven, Daten, Georgette Me Georgette You, Hearts Barrier, Kill KiSS, Kings, Masquerade Rhapsody Request, the common Phantom cards, Quaerere Lumina, Symbol II: Air, and Symbol IV: Earth.
3. Port uncommon cards and their one-card powers/actions, including Curiosity, Inner Cry and faithful Mantra/Divinity semantics, Utopia's purge replacement behavior, and the remaining Dazzling/Hype consumers.
4. Port rare cards and cross-card replay/copy behavior after their complete dependency subgraphs exist.
5. Port the nine STS1-disabled cards for serialization/library parity while keeping them unreachable from normal pools.
6. Run the complete 95-card matrix, power lifecycle checks, save/reload, both languages, full Sakiko regression, vanilla regression, and the declared multiplayer support gate before marking Phase N5 complete.

This order is refined from each card's STS1 Java imports and behavior body. Imports alone are not treated as semantic proof; every model is compared against its Java implementation before coding.
